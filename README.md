# Project Kaithi

**An Android keyboard project supporting the Kaithi script.**

Project Kaithi brings Kaithi-script typing tools to Android through three keyboard modes:

- **DIRECT** — type using the Kaithi keyboard layout.
- **ROMAN** — enter Roman letters and convert them to Kaithi script.
- **TRANSLATE** — access the app's translation interface for supported language options.

The app also includes light and dark themes.
