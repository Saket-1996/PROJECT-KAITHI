# Project Kaithi v1.0.0 — First Public Release

The first public APK release of Project Kaithi.

## Highlights
- DIRECT Kaithi keyboard mode
- ROMAN-to-Kaithi typing mode
- Translation interface with supported language options
- Light and dark themes

## Download
Download the APK attached to this GitHub Release.

## Installation
1. Download the APK to your Android device.
2. Open the downloaded file.
3. Review Android's installation prompt and proceed if you trust the source.
4. Enable Project Kaithi in Android keyboard settings and select it when typing.

## Notes
- This release contains the APK only; application source code is not published.
- Check the repository's privacy policy before enabling the keyboard.
- Report reproducible issues through the repository's Issues page, without posting private text or sensitive information.
